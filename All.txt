### Step 2: Prepare Files

```

 ├── index.html
 ├── about.html
 ├── contact.html
 ├── error.html
 └── images/banner.jpg
```

---

### Step 3: Upload Website Files

1. Bucket → Upload
2. Add all HTML + images folder
3. Upload

---

### Step 4: Enable Website Hosting

1. Bucket → Properties tab
2. Static Website Hosting → Edit
3. Enable
4. Index document: `index.html`
5. Error document: `error.html`
6. Save

---

### Step 5: Add Bucket Policy Public Access

Bucket → Permissions → Bucket Policy → Paste:

```json
{
 "Version": "2012-10-17",
 "Statement": [
  {
   "Sid": "PublicReadGetObject",
   "Effect": "Allow",
   "Principal": "*",
   "Action": "s3:GetObject",
   "Resource": "arn:aws:s3:::my-static-web-demo-123/*"
  }
 ]
}
```

Save changes

---

### Step 6: Access Website

1. Properties → Static Website Hosting
2. Copy Endpoint URL
3. Open in browser

✅ Website hosted

---

## PART B: Enable Versioning

1. Bucket → Properties
2. Bucket Versioning → Edit
3. Enable → Save

---

## PART C: Cross Region Replication

1. Create Destination bucket in different region
2. Enable Versioning in both buckets
3. Source bucket → Management → Replication Rules
4. Create rule → Apply to all objects
5. Destination → Select destination bucket
6. IAM Role → Create new role
7. Save rule

```bash
sudo blkid
```

```bash

```

```

```
